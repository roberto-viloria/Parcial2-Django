# Gestión de Proyectos y Tareas

Backend desarrollado con Django y Python para administrar proyectos y sus tareas.

## Tecnologías
- Python
- Django
- SQLite

## Modelos
- Proyecto: nombre, descripción y fecha de inicio.
- Tarea: título, estado de finalización y proyecto relacionado.

## Ejecución
1. Activar el entorno virtual.
2. Instalar dependencias con `pip install -r requirements.txt`.
3. Ejecutar `python manage.py migrate`.
4. Ejecutar `python manage.py runserver`.

El administrador de Django permite gestionar los proyectos y las tareas.
